# Home card backgrounds

Generated with the built-in ImageGen tool on 2026-08-19. PNG masters live in
`ProductionAssets/Raster/Home/Cards/`; production HEIC files live in
`ProductionAssets/Optimized/Home/Cards/` and ship from the app-only Home catalog.
The existing Home hero was supplied as a style, lighting, material, and palette
reference only for each generation.

## Shared direction

Photoreal premium architectural visualization with restrained AR overlays,
charcoal and warm neutral materials, and controlled `#7C3AED` / `#A78BFA`
accents. No text, letters, digits, logos, watermarks, people, phone mockups, UI
panels, random particle confetti, or cyberpunk excess.

## Scan code

Landscape 3:2. An abstract, deliberately non-scannable square registration target
made from raised matte tiles on a dark wall, framed by violet camera corners and
crossed by a narrow scan plane. Keep the left side quiet for native card copy.

## Enter code

Landscape 3:2. Unlabelled frosted-glass input tiles float in a precise horizontal
row over a dark architectural grid; one cell carries a violet insertion glow.
No characters appear inside the tiles. Keep the left side quiet for native copy.

## Object tracking

Portrait 2:3. A matte geometric sculpture stands on a minimal printed registration
target with a perspective-correct violet 3D bounding box, anchored feature points,
and a coordinate origin. Dark lower region for native card copy.

## Navigation

Portrait 2:3. A grounded violet AR path bends through a refined corridor toward a
soft destination beacon, with sparse feature points attached to architectural
edges. Strong central depth and a dark lower copy region.

## Localization

Portrait 2:3. A translucent camera frustum converges on structural feature points
and resolves into a luminous floor coordinate origin with a restrained cool-blue
confidence halo. Dark lower region for native card copy.
